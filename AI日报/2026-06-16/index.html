至少一个&符号上的Cloudflare CAPTCHA

📰 Simon Willison's Weblog 🕐 2026-06-16 08:21 🔗 原文
今日学习：Cloudflare CAPTCHA（现称“Web Application Firewall > Custom rules > Managed Challenge”）用于阻止爬虫过度抓取本站分面搜索引擎。但即使是简单的 `?q=term` 搜索也会触发验证，令人困扰。通过 Claude Code 调试后，发现可注册如下规则，使 CAPTCHA 仅对包含至少一个 `&` 的搜索 URL 生效：`(http.request.uri.path wildcard r"/search/*" and http.request.uri.query contains "&")`。现在 `/search/?q=lemur` 不再触发验证！另附：尝试用 Claude Code 集成 Cloudflare MCP 的笔记，但最终未成功。
