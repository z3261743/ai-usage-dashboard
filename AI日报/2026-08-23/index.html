本次发布为 llm 0.33，主要亮点包括：升级至 OpenAI Python 库 3.x，并将 HTTP 客户端依赖从 httpx 切换至 httpx2（#1608, #1631）。此前已发布 0.32.1 快速修复，但此次为更全面的解决方案。`llm embed` 和 `llm embed-multi` 命令现支持 `--key` 参数。Python 中的 `EmbeddingModel.embed()`、`EmbeddingModel.embed_multi()`、`Collection.embed()` 及 `Collection.embed_multi()` 方法也接受 `key=` 参数，将解析后的每次调用密钥传递给嵌入插件，而不改变共享模型状态。现有读取 `self.key` 的插件通过兼容性回退机制继续正常工作（感谢 ChrisJr404，见 #757, #1620）。嵌入模型现采用与常规 LLM 模型相同的密钥模式。此外，`llm prompt` 的 `-t/--template` 参数现可重复使用，以组合多个模板。
