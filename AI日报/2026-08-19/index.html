Sentence Transformers 是一个 Python 库，用于处理和训练嵌入及重排序模型，适用于检索增强生成、语义搜索等场景。在 v6.0 更新中，它新增了第四种模型类型：`MultiVectorEncoder`，支持 ColBERT 风格的晚期交互检索。任何 PyLate 检查点和 Stanford-NLP ColBERT 检查点均可直接加载，同时 colpali-engine 模型（用于视觉文档检索）也能通过熟悉的 API 使用，与密集、稀疏和重排序模型一致。常规嵌入模型将整个文本压缩为一个向量，而多向量模型则为每个 token 保留一个向量，并通过 MaxSim 计算查询与文档的得分。
