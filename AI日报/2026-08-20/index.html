sqlite-utils 4.2.1

📰 Simon Willison's Weblog 🕐 2026-08-14 07:53 🔗 原文
Release: sqlite-utils 4.2.1 修复了 sqlite-utils 4.2 中的一个崩溃 bug。我引入了类似 `from typing_extensions import Self` 的代码，但发现 typing-extensions 包未被列为 sqlite-utils 的依赖项——它是由开发依赖组中的其他依赖安装的，但当你直接使用 `uvx sqlite-utils` 时，这些依赖不会被包含。作为修复的一部分，我找到了运行冒烟测试的方法，以确保 CLI 工具在没有这些开发依赖的情况下仍能正常工作，可从项目检出中运行：`uv run --isolated --no-default-groups sqlite-utils --help`。`--no-default-groups` 参数阻止安装默认开发组，而 `--isolated` 意味着即使存在包含额外内容的 `.venv/` 文件夹，也会被忽略。
