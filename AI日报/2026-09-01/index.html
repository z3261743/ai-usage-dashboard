uv 0.12.0

📰 Simon Willison's Weblog 🕐 2026-07-29 05:51 🔗 原文
uv 0.12.0 版本带来了一些有趣的破坏性变更，尤其是 `uv init` 命令生成的默认项目结构。`uv init` 是 uv 创建新项目的快捷方式。在之前的 0.11.x 版本中，运行 `uv init uv-init` 会生成一个包含 `main.py` 的目录。而在 uv 0.12 中，`uv init` 默认生成 `src/` 布局的包，不再将 `main.py` 放在项目根目录。同时，它配置了 `uv_build` 后端，用于在运行 `uv build` 时构建 wheel 和 `.tar.gz` 分发文件。此外，它还设置了 `uv-init` 作为脚本别名，当运行 `uv run uv-init` 时，会执行新定义的 `main()` 函数。这些变更旨在优化项目结构和构建流程，但可能影响现有用户的习惯。
