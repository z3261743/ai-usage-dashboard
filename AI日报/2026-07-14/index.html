DOOMQL

📰 Simon Willison's Weblog 🕐 2026-07-14 06:34 🔗 原文
DOOMQL 由 Peter Gostev 基于 GPT-5.6 Sol 构建，源于一个刻意反常规的问题：如果 SQLite 不只是游戏的数据存储，而是游戏引擎本身会怎样？结果诞生了一款小巧的类 Doom 游戏，其中移动、碰撞、敌人、战斗、进度以及屏幕上的每个 RGB 像素均由 SQL 控制。它实现为 Python 终端脚本，运行后会创建 SQLite 数据库，可通过 Datasette 探索。核心是一个利用递归 CTE 在 SQLite 中实现完整光线追踪的庞大 SQL 查询。

使用开源内核调度器现代化Meta广告服务

📰 Engineering at Meta 🕐 2026-07-14 00:00 🔗 原文
TL;DR：在Meta的规模下，毫秒级的延迟退化会对广告性能产生显著的负面影响。当一次Linux内核升级可能影响Meta广告服务集群的延迟时，我们采用了基于BPF的可扩展调度框架sched_ext，为广告投放工作负载定制调度策略。结果：广告检索阶段尾部延迟（99百分位）降低28%，节省3.28兆瓦电力，广告排序数量增加1.1%，证明了针对特定工作负载的调度优化可直接驱动业务价值。为什么广告延迟重要：Meta的广告服务集群在服务平台入口处平均每秒处理超过500万次请求，每日超过4000亿次。
