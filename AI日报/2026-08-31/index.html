LLM 0.32rc1 中新增的 content-addressable logs 旨在支持 OpenAI Chat Completion 风格的请求，其中每条传入消息会扩展之前的对话。例如，通过 curl 发送请求，包含用户和助手的多轮消息，如询问法国首都后回答巴黎，再问德国。在此场景中，对话状态由客户端跟踪，因此每个请求会越来越长。LLM 的新 schema 设计正是为了应对这一需求，确保高效处理此类递增式对话。

LLM 0.32rc1 版本发布，完成了自 0.32a0 开始的工作。该版本引入新的 schema 设计，能更好地捕捉最新模型家族中提示和响应的细节。最重要的变化是采用内容可寻址哈希 ID 存储消息，实现数据库去重，并支持分叉对话中的消息树表示。由于涉及重大 schema 变更（仅新增表，旧数据不受影响），建议在升级前备份现有 logs.db：`llm logs backup logs-backup.db`。此外，该 RC 版本还新增了对 gpt-5.6-sol、gpt-5.6-terra 和 gpt-5.6-luna 的支持。
