datasette-apps 0.4a0

📰 Simon Willison's Weblog 🕐 2026-11-15 12:02 🔗 原文
发布：datasette-apps 0.4a0。Datasette Apps 是运行在 Datasette 内的沙箱化 HTML 和 JavaScript 应用，类似 Claude Artifacts，但可对数据执行 SQL 查询。0.4a0 新增链接支持：可通过 URL 中的 #fragments 链接到应用，应用能读取并使用这些片段；支持的 URL scheme 会反馈给 Datasette Agent，助其编写可相互链接的应用。例如，一个应用展示特定记录详情，另一个独立应用搜索记录并链接到前者中的对应展示。标签：datasette-agent、datasette-apps、datasette、urls。
