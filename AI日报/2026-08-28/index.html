llm-anthropic 0.26

📰 Simon Willison's Weblog 🕐 2026-08-05 06:00 🔗 原文
llm-anthropic 0.26 版本发布，基于 LLM 0.32 引入多项新特性：新增 claude-fable-5、claude-sonnet-5 和 claude-opus-5 模型。支持 WebSearch、WebFetch、CodeExecution 和 AnthropicMCP 的服务器端工具，可通过 LLM 的 -T 接口或 Python tools= 使用，取代了原有的 -o web_search* 选项。升级至 llm>=0.32 后，推理、工具调用、工具结果及服务器端工具结果均以类型化事件流式传输。llm CLI 提示的推理过程默认显示到标准错误，除非使用 --hide-reasoning/-R 隐藏。简化了扩展思考为 thinking 和 thinking_effort（低、中、高、超高或最大）参数。Claude 5 模型默认启用思考，Sonnet 5 和 Opus 5 可通过 -o thinking 0 禁用，而 Fable 5 始终启用思考。
