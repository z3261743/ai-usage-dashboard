simonw/browser-compat-db

📰 Simon Willison's Weblog 🕐 2026-06-25 07:59 🔗 原文
受 Mozilla 新推出的 MDN MCP 服务启发，开发者 simonw 创建了 browser-compat-db 项目。该项目将 Mozilla 的 mdn/browser-compat-data 仓库（包含大量浏览器兼容性数据）转换为 SQLite 数据库。仓库中包含一个由 Claude Code for web (Opus 4.8) 生成的脚本，使用 sqlite-utils 完成转换。生成的数据库约 66MB，开发者希望其能通过 GitHub CDN 提供并开放 CORS 头。由于 GitHub Releases 不支持 CORS，但普通仓库文件支持，因此使用 Codex Desktop (GPT-5.5) 构建了一个 GitHub Actions 工作流，生成数据库后强制推送到一个名为 db 的“孤立”分支。用户可直接下载该数据库，因其托管时已开放 CORS 头。
