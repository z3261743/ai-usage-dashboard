软弃用 re.match()

📰 Simon Willison's Weblog 🕐 2026-09-11 22:47 🔗 原文
Python 有一个软弃用（soft deprecation）的概念，即 API 被标记为“不应再用于编写新代码”，但不承诺/威胁在未来移除它们。Python 3.15 发布经理 Hugo van Kemenade 介绍了在即将发布的 3.15 版本中，古老但令人深感困惑的 re.match() 函数已被软弃用。现在它有了更清晰的替代名称 re.prefixmatch()——反映了它只在字符串开头锚定匹配而不在结尾锚定。大多数情况下，你可能更需要 re.search()（在字符串任意位置匹配该模式）或 re.fullmatch()（匹配整个字符串）。来自 Lobste.rs。标签：python、regular-expressions
